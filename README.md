# 婚外情无效赠予法律数据集

## 项目概述

本项目是一个关于**婚外情无效赠予**主题的法律实务数据集，包含相关法规、典型案例及实务分析文章。数据集旨在为法律实务工作者提供婚外情赠予财产返还纠纷的法律依据和裁判参考。

## 数据源选择理由

### 主题背景

婚外情无效赠予案件是近年来婚姻家庭纠纷中的常见类型，涉及以下核心法律问题：

1. **夫妻共同财产的认定**：赠予财产是否属于夫妻共同财产
2. **赠予行为的效力**：基于婚外不正当关系的赠予是否因违背公序良俗而无效
3. **财产返还责任**：无效赠予后受赠方是否应当返还财产
4. **善意第三人抗辩**：受赠方主张不知赠予方已婚的抗辩是否成立

### 数据源简介

本数据集数据来源于：

| 来源类型 | 具体来源 | 内容说明 |
|----------|----------|----------|
| **法律法规** | 国家法律法规数据库 (flk.npc.gov.cn) | 《民法典》相关条文、司法解释 |
| **司法指导** | 最高人民法院官网 | 典型案例指导、检察监督指引 |
| **实务文章** | 法律实务分析整理 | 婚外情赠予法律问题分析 |
| **案例数据** | 模拟创建 | 典型案例用于展示脱敏处理 |

**选择理由**：
1. 婚外情无效赠予是实务热点问题，数据具有实用价值
2. 涉及《民法典》多个编章，法律关系复杂，适合学习研究
3. 案例数据包含当事人信息，便于展示脱敏处理技术
4. 数据结构规范，便于知识库建设和检索应用

#### 2. 手动整理（实际采用）

因自动化采集遇到技术障碍，改用手动整理方式：

1. 访问国家法律法规数据库 (https://flk.npc.gov.cn)
2. 搜索"民法典"、"赠与"、"婚姻家庭"等关键词
3. 手动提取相关条文内容
4. 按照规范格式整理保存

**采集内容**：
- 《民法典》总则编（无效民事行为相关条文）
- 《民法典》婚姻家庭编（夫妻财产制度）
- 《民法典》合同编（赠与合同）
- 相关司法解释

## 脱敏处理方法

### 脱敏对象

案例数据包含以下需要脱敏的主体信息：

| 信息类型 | 示例 | 脱敏后 |
|----------|------|--------|
| **姓名** | 张美玲、李建国 | 张某某、李某某 |
| **身份证号** | 330106198005154567 | ****************** |
| **手机号** | 13812345678 | *********** |
| **住址** | 杭州市西湖区XX花园12栋501室 | 浙江省杭州市某区 |
| **案号编号** | （2024）浙0106民初2345号 | （2024）浙0106民初XXXX号 |

### 脱敏规则

#### 1. 姓名脱敏

```python
def desensitize_name(text):
    """保留姓氏，替换为'某某'"""
    for name in NAMES_TO_DESENSITIZE:
        replacement = name[0] + '某某'
        text = text.replace(name, replacement)
    return text
```

**示例**：
- 张美玲 → 张某某
- 李建国 → 李某某
- 王小红 → 王某某

#### 2. 身份证号脱敏

```python
def desensitize_id_number(text):
    """18位身份证号全部替换为星号"""
    pattern = r'\d{6}[12]\d{3}[01]\d{2}[0-3]\d{2}\d{3}[\dXx]'
    return re.sub(pattern, '******************', text)
```

**示例**：
- 330106198005154567 → ******************

#### 3. 地址脱敏

```python
def desensitize_address(text):
    """保留省市，隐藏详细地址"""
    patterns = [
        (r'住[^，。\n]{15,60}', '住某省某市某区'),
        (r'住浙江省杭州市[^，。\n]+', '住浙江省杭州市某区'),
    ]
    for pattern, replacement in patterns:
        text = re.sub(pattern, replacement, text)
    return text
```

**示例**：
- 杭州市西湖区XX花园12栋501室 → 杭州市某区

#### 4. 案号脱敏

```python
def desensitize_case_number(text):
    """保留年份和法院代码，替换具体编号"""
    pattern = r'（\d{4}）([浙京沪粤]\d{2,4})[^\d]*(\d+)号'
    replacement = r'（\g<1>）\g<2>民初XXXX号'
    return re.sub(pattern, replacement, text)
```

**示例**：
- （2024）浙0106民初2345号 → （2024）浙0106民初XXXX号

### 脱敏脚本执行

```bash
python3 scripts/desensitize.py
```
